# CARPINCHO: THE LOST RAILWAY

Jogo 3D web em HTML5, CSS3, JavaScript, Three.js e Vite.

## Executar

```bash
npm install
npm run dev
```

Para validar a build:

```bash
npm run build
npm run preview
```

O código do cliente está em `js/`, os estilos em `css/` e o servidor multiplayer em `server/`.
