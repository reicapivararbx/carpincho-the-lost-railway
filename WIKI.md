# Wiki — CARPINCHO: THE LOST RAILWAY

## Arquitetura

O projeto usa Vite como ferramenta de desenvolvimento/build, Three.js para a cena 3D e módulos ES para gameplay. Os sistemas estão separados em `js/player`, `js/train`, `js/world`, `js/inventory`, `js/crafting`, `js/combat`, `js/enemies`, `js/quests`, `js/ui`, `js/save` e `js/data`.

## Fluxo local

Instale as dependências com `npm install`, inicie com `npm run dev` e gere a build com `npm run build`. O caminho publicado usa a base `/railsgame/` definida em `vite.config.js`.
